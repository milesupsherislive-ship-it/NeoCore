# NeoCore — корпоративный сайт компании биопротезирования

Адаптивный корпоративный веб-сайт (лендинг) вымышленной компании NeoCore, 
специализирующейся на бионических протезах, искусственных органах и нейроинтерфейсах.

## Концепция и цель проекта
Сайт знакомит пользователей с технологиями биопротезирования, демонстрирует 
каталог продукции, тарифные планы и отзывы пациентов, а также позволяет 
оставить заявку на консультацию через форму обратной связи.

## Прикладные цели пользователя
- Изучить каталог продукции (бионические руки, ноги, органы, нейроинтерфейсы)
- Сравнить тарифные планы и выбрать подходящий
- Ознакомиться с этапами биопротезирования и отзывами пациентов
- Оставить заявку на консультацию через форму обратной связи

## Инструментально-языковая база
- React 18 (JavaScript, JSX)
- HTML5 / CSS3
- Bootstrap 5 (сетка, навигация)
- jQuery (плавный скролл)
- Font Awesome (иконки)
- Canvas API (анимированный фон)

## Последовательность запуска (развёртки)
1. Установить Node.js (LTS)
2. `git clone https://github.com/milesupsherislive-ship-it/React.git`
3. `npm install` — установка зависимостей
4. `npm start` — запуск в режиме разработки (http://localhost:3000)
5. `npm run build` — сборка производственной версии
6. `npm run deploy` — публикация на GitHub Pages (ветка gh-pages)

Проект развёрнут и доступен по ссылке: 
https://milesupsherislive-ship-it.github.io/React/
